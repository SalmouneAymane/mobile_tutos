| Stage | Corresponding tasks |
|---|---|
| Define scope | Define the perimeter (consult, author, modify, delete). Identify the deliverable. |
| Design | Define the structure of the table categories (id, name, colour, icon). Identify the API endpoints needed. Design the interface (form + table). |
| Develop | Create the SQL table. Create the API endpoints (GET, POST, PUT, DELETE). Create the HTML page with the form and the table. Connect it to the API via fetch(). |
| Test | Verify the display of the list. Test creation, modification, and deletion. Verify error messages in case of invalid input. |
| Validate | Check that all tasks are completed. Validate the functionality with the initial requirements. |
